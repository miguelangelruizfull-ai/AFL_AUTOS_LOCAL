# MUSICA USADA — AFL AUTOS

Actualizado: 2026-09-27

## OBJETIVO

Evitar repetir música o audios ya publicados en contenido de AFL Autos.

Este archivo es un registro de uso.
NO almacena archivos de audio ni música.

## REGLA

Antes de producir o publicar:

- Reel;
- TikTok;
- Historia con audio;
- video para Facebook/Instagram;

consultar este registro.

Después de publicar una pieza con música, registrar el uso.

## CAMPOS

| Fecha | AFL-ID | Vehículo | Plataforma | Pieza | Audio / canción | Artista / fuente | Estado |
|---|---|---|---|---|---|---|---|

## ESTADOS

- `PUBLICADO` — ya se usó públicamente; evitar repetir.
- `APROBADO_NO_PUBLICADO` — reservado para una pieza; todavía puede cambiarse.
- `DESCARTADO` — no cuenta como uso.
- `DESCONOCIDO_HISTORICO` — publicación antigua detectada pero audio pendiente de identificar.

## REGLAS DE USO

1. No marcar un audio como usado solo por haberlo considerado.
2. La condición principal para bloquear repetición es `PUBLICADO`.
3. Si un mismo audio se usó en varias plataformas para la misma pieza, registrar cada plataforma o indicar la distribución correspondiente.
4. Si se reutiliza deliberadamente un audio, debe quedar registrado como decisión explícita.
5. No guardar archivos musicales en GitHub ni en Drive por esta función.
6. No copiar ni archivar música protegida; registrar únicamente metadatos de referencia.
