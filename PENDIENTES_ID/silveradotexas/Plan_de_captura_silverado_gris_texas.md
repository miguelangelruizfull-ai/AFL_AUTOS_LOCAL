### DATOS QUE ESTA CAPTURA DEBE INTENTAR RESOLVER

* color comercial exacto;
* existencia real de emblema `Texas Edition`;
* evidencia visible del 4x4;
* marca/medida visible de llantas;
* equipamiento visible;
* condición real de caja y trasera.

No resolver por fotografía: documentación, historial, estado mecánico o especificación exacta de transmisión sin una fuente adicional.

### NO CAPTURAR PARA USO COMERCIAL

* VIN completo;
* etiqueta de puerta con VIN;
* odómetro legible;
* documentos o datos personales;
* placas/documentos como protagonista.

Tampoco ocultar daños reales ni alterar color, carrocería, rines o condición.
