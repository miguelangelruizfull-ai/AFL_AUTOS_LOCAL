# PUBLIC_EVIDENCE — Política de evidencia profesional

Actualizado: 2026-09-27

## Objetivo

Concentrar en este repositorio público únicamente la evidencia profesional que siga siendo útil cuando los demás repositorios de trabajo se mantengan privados.

## Superficie pública autorizada

- Aplicación AFL AUTOS LOCAL.
- Portafolio técnico sanitizado: `PORTAFOLIO/index.html`.
- Código necesario para que la aplicación pública funcione.
- JSON públicos sanitizados.
- Documentación que explique arquitectura conceptual, uso y privacidad sin revelar fuentes privadas.

## Capacidades que sí conviene demostrar

1. Arquitectura de información:
   - fuentes de verdad;
   - contratos JSON;
   - validación;
   - trazabilidad;
   - separación vigente/histórico.

2. Desarrollo web práctico:
   - HTML;
   - CSS responsive;
   - JavaScript;
   - interfaces JSON-driven;
   - GitHub Pages.

3. Automatización e IA aplicada:
   - handoffs;
   - human-in-the-loop;
   - guardrails;
   - continuidad entre sesiones;
   - automatización posterior a validación.

4. Operación digital:
   - estados;
   - workflows;
   - checklists;
   - seguimiento;
   - medición y aprendizaje.

5. Privacidad por diseño:
   - PUBLICO != PRIVADO;
   - RAW privado;
   - datos sanitizados;
   - no exponer PII, VIN completo, IDs privados o credenciales.

6. Evolución de producto:
   - prototipo;
   - estandarización;
   - modularización;
   - gobierno;
   - interfaz operativa actual.

## No publicar

- repositorios internos completos;
- mapas detallados de arquitectura privada;
- rutas privadas;
- nombres/IDs internos innecesarios;
- Google Drive privado;
- Calendar IDs;
- teléfonos, PII o conversaciones;
- VIN completo;
- documentos;
- exportaciones RAW;
- multimedia privada;
- prompts internos que revelen lógica operativa;
- credenciales o secretos.

## Regla editorial

La evidencia pública debe responder:

- qué problema se resolvió;
- qué se diseñó;
- qué tecnología se utilizó;
- qué decisión de arquitectura fue importante;
- cómo se protegieron datos y fuentes;
- qué resultado puede verificarse.

No es necesario que el repositorio fuente siga siendo público.
